# AIU EO V2 — Final ImageGen Prompt Set

Generation method: **built-in ImageGen**  
Use case: **production-quality full-page desktop UI mockups**

## Shared reference and constraints

Use the selected AIU EO Living Event Blueprint image, then the finalized homepage, as strict visual references. Preserve the deep ink/navy, cobalt, amber, and off-white paper palette; condensed display headings; readable sans-serif body; documentary Indonesian corporate-event photography; route lines; coordinates; timestamps; torn-paper transitions; field notes; risk transformation; and departure-ticket CTA.

All pages must be buildable, responsive, accessible, and conversion-led. Avoid audio mixers, knobs, dials, playback controls, sliders, fake machinery, generic SaaS card grids, glassmorphism, fake evidence, fake testimonials, unverified metrics, invented certifications, emojis, and watermarks.

## Page prompts

### Homepage

Remove the hero control console completely. Create a direct editorial hero with “Corporate Outing & Event Management”, “Your next team experience starts here.”, supporting orchestration copy, Build My Event and Explore Destinations CTAs, documentary Cikereteg imagery, and one route line connecting brief → destination → live experience. Continue with proof, buyer problem, service/destination discovery, process, field report, Risk Before Magic, FAQ, and departure-ticket CTA.

### About

Create a founder-led origin and operating-philosophy story around “Built to make complex events feel effortless.” Show Clarity, Control, Accountability, and Safety; behind-the-scenes execution; a restrained team section; West Java operating footprint; and a proposal CTA. Do not imply a large corporation or invent awards/numbers.

### Services index

Create an outcome-led service chooser around “Not a package first. A purpose first.” Present Outing & Outbound, Company Gathering, Team Building & Offsite, and Custom Event Management as four distinct experience routes with buyer fit, typical duration/pax, inclusions, comparison, optional modules, and clear next action. Avoid generic equal-card layouts.

### Service detail

Create the reusable service-detail template using Outing & Outbound: “Step out of routine. Come back more connected.” Include buyer fit, problems solved, event-day route, packing-list inclusions/add-ons, experience paths, related destinations, sample proof, planning/safety, FAQ, and a preselected proposal ticket.

### Destinations index

Create a decision-led discovery page for Garut, Cikereteg, and Pangalengan around “Three landscapes. One stronger team.” Compare team objective, pace, journey profile, duration, pax, activities, season/logistics notes, and cross-destination journeys. It must feel like a field guide, not a travel-booking portal.

### Destination detail

Create the reusable destination template using Cikereteg: “Nature, culture, connection.” Include location facts, why it works, 1D/2D1N/3D2N modes, sample itinerary with timestamps, activity library, gallery, logistics, weather/season, indicative inclusions/exclusions, safety/contingency, relevant case, FAQ, and destination-preselected proposal ticket.

### Events index

Create a portfolio library as field reports around “Real events. Real decisions. Real impact.” Include one featured dossier with challenge → approach → execution → result, restrained filters, chronological dispatches, proof methodology, permission-safe client evidence, and proposal CTA. Mark unverified examples as SAMPLE / DEMO.

### Case-study detail

Create a reusable long-form field report using “Two Days. Stronger Together.” in Cikereteg for a 50-person team, explicitly labeled SAMPLE / DEMO. Include facts, challenge, goals/constraints, key decisions, two-day timeline, delivered scope, behind-the-scenes proof, Risk Before Magic, results/lessons, permission-safe testimonial state, gallery, related routes, and CTA.

### Process & Safety

Create an operational journey around “Magic on the day. Method behind it.” Show five phases, T-21 through H+7, You/AIU EO/Partners responsibilities, manifest/change controls, Risk Before Magic, contingency and escalation, privacy/data handling, milestone deliverables, FAQ, and proposal CTA. Do not invent insurance or certification claims.

### Request Proposal

Create a calm, accessible event-brief form around “Tell us where your team needs to go.” Structure it as About You → The Event → What Matters → Ready to Send. Include all qualification fields, optional budget, consent, supportive validation, desktop summary ticket, next steps, consultation alternative, and post-submit WhatsApp continuation. Never request health data or participant manifests.

### Contact

Create a human contact page around “Let’s find the right next step.” Prioritize Request a Proposal, then consultation. Follow with WhatsApp/email/phone/operating-area placeholders, general inquiry form, vendor/partnership routing, response expectations, operating footprint, FAQ, and departure-ticket CTA. Do not invent address, hours, or live availability.

### Privacy

Create a quieter, print-friendly legal page around “Your information. Handled with care.” Include sticky contents, readable legal sections, data-flow diagram, explicit public-form data limitation, rights/contact, legal placeholders, last-updated placeholder, and links to proposal/contact. Do not invent legal promises, entity information, retention periods, or policy dates.
